### Spring缓存清除增强服务(Cache Event)

###### **项目描述**：

Cache Event 是一个基于 Spring Boot 的分布式缓存事件管理框架，旨在解决分布式系统中缓存一致性问题。该项目提供了灵活的缓存清除机制，支持通过事件驱动的方式在分布式环境中同步清除缓存，确保各节点间缓存数据的一致性。

**责任描述**：

- 1.**需求分析与设计**。支持单体和分布式架构，设计缓存依赖图谱，并支持多级缓存处理。
- 2.基于Spring后置处理。注册缓存依赖管理，自动维护缓存依赖图谱，提供多种依赖关系存储实现。零侵入性的实现功能，易扩展，易维护。
- 3.自动化缓存清除。基于AOP拦截 @CacheEvict 注解方法，自动发布缓存清除事件。支持基于事件的缓存清除监听和处理。
- 4.灵活的配置机制。支持通过配置文件切换事件推送方式。可扩展的架构设计，易于添加新的事件推送机制。
